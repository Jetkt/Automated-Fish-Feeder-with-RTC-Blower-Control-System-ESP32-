# Automated-Fish-Feeder-with-RTC-Blower-Control-System-ESP32-
Sistem pakan ikan otomatis berbasis ESP32, RTC DS3231, &amp; LCD 16x2 untuk Pengabdian Masyarakat. Fitur: 3 jadwal pakan, durasi blower, penyimpanan Preferences (anti-mati listrik), navigasi tombol cyclic non-blocking, &amp; penanganan tahun kabisat.
